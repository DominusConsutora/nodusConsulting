# Página estática "Próximamente"

Carpeta lista para subir a un hosting estático.

## Archivos

- `index.html`: página principal.
- `styles.css`: estilos de la pagina.
- `assets/logo-nodus.png`: logo usado por el HTML.
- `assets/puerto-proximamente.webp`: imagen portuaria de apoyo visual.

## Subida

Subí el contenido completo de esta carpeta al directorio público del hosting, manteniendo la estructura:

```text
index.html
styles.css
assets/logo-nodus.png
assets/puerto-proximamente.webp
```

El email de contacto actual es `info@nodus.com.ar`. Si cambia, editalo directamente en `index.html`.
